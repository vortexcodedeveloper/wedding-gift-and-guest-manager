# مدیریت هدایا و مهمانان عروسی

ابزار تحت وب فارسی و واکنش‌گرا برای ثبت هدایا و مدیریت فهرست خانواده‌های مهمان عروسی. برنامه در یک فایل HTML و بدون نیاز به نصب یا Build اجرا می‌شود.

**این صفحه وب توسط ChatGPT ساخته شده است.**

## امکانات

- **هدایا:** ثبت و ویرایش پرداخت‌ها، دسته‌بندی بر اساس سمت عروس یا داماد، جست‌وجو، فیلتر، آمار مبالغ و خروجی CSV.
- **مهمانان:** ثبت اطلاعات تماس و تعداد نفرات خانواده، پیگیری وضعیت حضور، جست‌وجو، فیلتر و خروجی CSV.
- **امنیت:** قفل مستقل فهرست‌ها و آمار، مخفی‌کردن مقادیر آماری و رمزنگاری اطلاعات ذخیره‌شده در مرورگر.
- **پشتیبان‌گیری:** دریافت و بازیابی نسخه پشتیبان JSON برای هر بخش به‌صورت جداگانه.

## نگهداری اطلاعات و امنیت

اطلاعات در حافظه محلی (`localStorage`) همان مرورگر ذخیره می‌شود و بین دستگاه‌ها همگام‌سازی نمی‌شود. برای جلوگیری از ازدست‌رفتن اطلاعات، مرتباً نسخه پشتیبان JSON تهیه کنید.

**نکته امنیتی:** فایل‌های خروجی CSV و نسخه‌های پشتیبان JSON رمزنگاری نشده‌اند و ممکن است حاوی اطلاعات شخصی و مالی باشند. آن‌ها را در مخزن عمومی GitHub یا در اختیار افراد غیرمجاز قرار ندهید. خود فایل HTML را می‌توانید منتشر کنید؛ اما اطلاعات واقعی و فایل‌های خروجی را به مخزن اضافه نکنید.
